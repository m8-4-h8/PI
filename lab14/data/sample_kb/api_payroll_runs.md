# Payroll API v2 — розрахункові відомості

## POST /v2/payroll/runs — створити розрахунок

Створює розрахунок зарплати за період для працівників однієї юрособи. Потрібна роль `payroll_admin`. Запит ідемпотентний: передайте заголовок `Idempotency-Key`.

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| period | string, формат YYYY-MM | так | Період нарахування. Період має бути відкритим |
| legal_entity_id | uuid | так | Юрособа-роботодавець |
| employee_ids | array of uuid | ні | Якщо не вказано, беруться всі активні працівники юрособи |
| include_bonuses | boolean | ні | Додати премії з модуля Bonuses. За замовчуванням false |
| tax_profile | enum: general, simplified, diia_city | так | Податковий режим: загальний, ФОП-спрощений, Дія.Сіті |
| dry_run | boolean | ні | Лише порахувати, нічого не зберігати. За замовчуванням false |

```json
{"period": "2026-10", "legal_entity_id": "7f1c...", "tax_profile": "general", "dry_run": true}
```

### Коди помилок

| Код | HTTP | Значення | Що робити |
|---|---|---|---|
| ERR_4091 | 409 | Розрахунок за цей період уже існує | Змініть наявний через PATCH /v2/payroll/runs/{id} або видаліть чернетку |
| ERR_4092 | 409 | Період нарахування закрито | Відкрийте період: POST /v2/payroll/periods/{period}/reopen, потрібна роль chief_accountant |
| ERR_4093 | 409 | Розрахунок уже проведено в бухгалтерії | Створіть коригувальний розрахунок з type=correction |
| ERR_4221 | 422 | Невідомий tax_profile | Допустимі значення: general, simplified, diia_city |

## GET /v2/payroll/runs/{id} — отримати розрахунок

Повертає розрахунок з рядками по кожному працівнику: нараховано, ПДФО, військовий збір, ЄСВ, до виплати. Суми — у копійках, ціле число.

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| id | uuid | так | Ідентифікатор розрахунку |
| expand | string | ні | lines — додати рядки по працівниках |

### Коди помилок

| Код | HTTP | Значення | Що робити |
|---|---|---|---|
| ERR_4041 | 404 | Розрахунок не знайдено або належить іншій юрособі | Перевірте id і legal_entity_id токена |
